# Game Library

Personal game library manager built with Python, PySide6, and SQLAlchemy.

## Features

- Add games to the library
- Assign a status to each game
- Edit existing games
- Delete games with confirmation
- Persist game data using SQLite
- Display games using Qt's Model/View architecture

## Technologies

- Python
- PySide6
- SQLAlchemy
- SQLite
